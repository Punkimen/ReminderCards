# Правила для server

- Пишите новые и изменяемые комментарии в коде и SQL на русском языке, чтобы было проще сохранять контекст изменений.
- Сохраняйте имена идентификаторов и машинные директивы в исходном виде. Например, служебные комментарии `// indirect`, `//go:build` и `//go:embed` переводить нельзя.
